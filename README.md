# Yash Khope - Video Editor Portfolio

A cinematic, responsive portfolio for Yash Khope, focused on video editing, visual storytelling, pacing, sound design, and selected work.

## Run locally

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
```

## Structure

- `src/App.jsx` contains the portfolio sections and editor-focused content.
- `src/index.css` contains the visual system, responsive layout, and light/dark presentation.
- `src/components/BounceCards.jsx` contains the animated project showcase.
- `src/components/ui/floating-navbar.jsx` contains the floating navigation.
- `public/Yash1.JPG` is the hero image.
- `public/Profile.jpg` is the profile image.
- `public/Yash_Resume.pdf` is the downloadable resume.

The Selected Projects section links to two supplied Google Drive edits, the House of Creations website, and the full video portfolio folder on Google Drive.

## Deploy on Vercel

Import the repository into Vercel. The project is configured as a Vite app:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
